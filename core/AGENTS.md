# Core

Use DEAL v1.5 only: a TypeScript syntax subset with checked semantics, not unrestricted TypeScript. Records read as unknown; use checked assertions/refinement, inferred for-of bindings, Promise results and unknown catches. Missing optional fields yield undefined, not null. Validate/copy decoded arrays without retagging invariant descriptors; preserve typed-array identity and explicitly write back copied collections when mutations must persist. Never rename wire properties while changing reserved bindings.

Keep portable graph validation, expressions, initialization, codecs, workflow policy and view emission in core/composition. Compile independent programs into separate Java namespaces. Host bindings transform compiler-parsed syntax and transport data; they must not reproduce behavioral policy. Contextualize nominal literals before Record storage. Generate closed shape checks from ui/fragment-contract.json.

source-agent.deal owns maintained submission, measured typed custom sections, explicit full-source fallback and the staged pair. submit_compact supplies title/fragments/commands/display: independent named instances, semantic configuration, pure formulas, disclosed bindings and command targets. Fragments own state/actions/views; core derives dependencies. Nested arguments/roles/quotas are constrained data, never JSON strings or source. Keep low-level graph/custom guidance separate. Never infer requirements or inject task answers.

Materialize once atomically without provider reads. Malformed plans leave files absent. Rejected compilation returns exact expanded bytes; thereafter allow read_file/edit_sources/check_sources only, never reassembly or hidden regeneration. Initial write_file requires explicit fallback. Batch independent paired writes only while both files are absent; preflight the whole batch, disable batching after either exists and preserve single-write recovery. Core emits initialWrites from staged state.

source-repair.deal accepts only unique, disjoint exact edits against the host-bound revision, without count/size ceilings. Reject overwrite, nonunique/no-match and overlapping edits without changing either file. Report zero-based edit index, target, overlapping/other-file match counts and all occurrence lines; show literal numbered context for the first eight occurrences, with remaining ranges readable. Preview limits never constrain edits. read_file uses inclusive 1-based ranges, both nullable for full reads; reject invalid bounds without clipping. Line numbers are not edit text. Recheck the complete pair.

Keep canonical source/current diagnostics and only the latest complete assistant/tool exchange in active repair context; retain earlier exchanges in unified evidence. Preserve native tool identities. Models never supply digests or boundary tokens. Provider adapters carry native messages, not source envelopes. Failed patches preserve the valid base; malformed native calls recover before admission. Repeated replies are feedback, not terminal conditions. Generation ends on checked acceptance or cancellation, without attempt/repetition/elapsed ceilings. Classified transport failures remain transport failures. Record initial/repair operations and all fallback/custom work; optimize locality, latency and preservation, not zero repairs.

Keep invariant guidance/contracts before variable context. Prompt assembly belongs in generation-guidance.deal; prose/examples in ui/. Generated guidance contains exact assets, lexer facts and pack AST facts, including defaults/typed children—not build-tool-selected arguments or rules. Maintained facts use bare component names and contracts, not raw calls/action source. host/sample is fixture-only. Compiler/runtime-check examples for explicit read, pending/success/failure/retry, local comparison and immutable updates.

Keep catalogue offer/lowering in app-linked compiled policy. Only fully specified offers without inferred questions may lower directly; others enter composition without another chooser. Core owns fallback, recovery and admission. Native boundaries validate generic answers; app policy owns domain relations. source-literals.deal owns escaping. policy-data supplies shape conversion, lowercase and UTF-16 mechanisms, not domain decisions. Never invent provider fields, prices, IDs or local substitutes for required reads.

Catch expected JSON/shape rejection only; keep awaited operational primitives outside shape catches. INVALID_JSON means invalid JSON, not arbitrary parse failure. candidate-check.deal validates two source strings against the native checker. Host-serialized JSON is an internal ABI, not model output. Repair structured candidate diagnostics only; propagate unexpected compiler/resource/cleanup failures.

repair-guidance.deal is advisory, never edit authority. List every diagnostic location; merge nearby per-file windows without repeating lines. Bound and label context omissions, retaining read_file access. Route advice by structured code, language and offending line; generic parser errors must not trigger unrelated rewrites. Derive reserved words from the lexer and require a diagnostic-column identifier match before advising renaming. Align examples with v1.5 assertions and presence; keep provider keys intact. Include actual diagnostic filenames, patch targets and pack-derived component contracts.

Treat host declarations and host/check-result.json as canonical. Align native replies, core reads and generated metadata. Trusted host imports provide orchestration only; generated experiences receive checked candidate identities, not administration APIs. Hosts revalidate context/catalogue before activation. Register discovery stages in logging.deal and observe patches without routine source-content metrics. Preserve noninterfering observation and operational failures.

Keep ui/generation-guidance.md aligned with current language, view grammar and renderer pack. Tool arguments decode to literal source/Unicode; never rewrite accepted source or filter rendered text. Explain filenames, exports, pack import, When/ForEach and typed payload events. Preserve provider prerequisites, current-input recomputation and honest pending/infeasible/failure states. Task controls/results precede explanations; Inspect owns diagnostics/provenance and native consent owns authority. Verify fresh generated output separately from deterministic examples and visual acceptance; retain failed evidence.
