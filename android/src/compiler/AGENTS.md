# Compiler

Use the current DEAL 1.4 and Deal UI compilers and matched runtime/stdlib assets. Manifest versions must match the compiler; do not retain an old compiler lane for saved generated source. Instrument each invocation separately through the unified DEAL logger, including outcome and bounded diagnostic artifacts when capture is enabled; no independent compiler log sink. Limit generated application externals to published application declarations.

Stage the authoritative checked `ui/values` module and embedding-owned `fragments` modules from the matched distribution; do not inject app-specific helpers or copy generated source into a library. Authored input transitions/initializers and comparison calculations live in ui/fragments. Instantiate authored fragment views through parsed Deal UI nodes with explicit bindings; never replace source substrings or let custom graphs select private fragment operations. Check against the supplied renderer pack. Reject pack/renderer disagreement and unsupported effect features.

Compile in candidate staging. Remove failed staging and return candidate diagnostics with local paths removed. Include diagnostic details in rejection exceptions so no-model checking and replay preserve the cause. Attach cleanup failures to the exception actually thrown after diagnostic translation, not to a discarded diagnostic.

A nonzero compiler status alone is not candidate rejection. Repair only structured source diagnostics attributed to the generated application; stop on missing/malformed reports, project configuration, framework/declaration diagnostics, backend or publication failures. Do not expose native paths in operational errors.

Collect compiler phase receipts through the invocation-scoped compiler observer and unified logger; preserve failure-path timings, isolate concurrent invocations and never change acceptance based on telemetry. Parent codegen totals overlap lowering/emission children; do not add them as independent time.

SelectionComposition lives in consuming host-test fixtures, not the shipping library. Keep its experimental operators behind explicit host-test admission; do not register them in generation or count supplied-plan passes as live authoring evidence. Keep additive category coverage distinct from exclusive requirement assignment, preserve external authority, and reject unknown component identities and malformed quantities rather than inventing feasibility.

Authored DEAL fragment instance builders own independently instantiable state/handler/view construction selected by semantic configuration, pure formulas and disclosed capability/field bindings. FragmentComposition only transports compiled composition data; core/composition/view-binding.deal binds compiler-parsed view trees exported mechanically by EmbeddingSyntax. Keep nested native configuration as actual constrained data in ui/fragment-contract.json. Derive dependency identities/order in core/composition/compose.deal from schema-derived formula slots. Resolve ports and optional presence explicitly; derive command execution, never ask the model for state graphs or workflow steps. Exclusive role assignment consumes distinct physical units; aggregate direct and bundle component demand against authoritative shared stock. Keep additive allocation quotas separate. Legacy whole-behavior fixtures belong only in consuming host tests, never the library authoring route. Expand only before materialization; never accept task answers or executable source. BehaviorCandidate transports plans and catalogue data to core/composition/lowering.deal and isolates explicit custom sections; accept data and typed references, never executable source strings in maintained operations. Derive dependencies from every nested reference and validate capability argument/result bindings against disclosed contracts. Keep provider names/data and task expectations out of generic operators. Compiler/runtime fixtures must exercise collection ownership, sequential provider workflows and infeasible results, not just schema acceptance.

core/composition/lowering.deal owns maintained and explicitly marked typed custom-section initial construction; native adapters do not author expression, control, provider or workflow bodies. Validate closed shapes, identifiers, disclosed imports, numeric controls and dependency references/cycles before returning a pair. Require explicit initializers and keep custom computation under ordinary compiler/borrowed-state checks; never call providers, infer domain answers or regenerate existing staged files. Keep allocation and exclusive-role/shared-stock search in checked ui/fragments/support modules; portable lowering adapts typed rows and selected quantities. Recalculation must copy its borrowed input before writing derived fields. Keep generated async errors/pending distinct from success. Reset workflow success markers before awaiting, fence pending completions on input invalidation and merge only workflow-owned fields. Keep dependency ordering, per-workflow ownership/read sets and propagated invalidation in core/composition/execution.deal; portable lowering binds its returned identities and typed fields. Include nested and derived references and reject multiple async owners for a field. Screen loading/error are presentation aggregates, not request identity. Ordinary forward SessionClock ticks must not cancel work; trust-loss events fence pending completions. Quote TTL starts at each reply's conservative receipt time, never batch completion or a later tick. Maintained quoted alternatives enumerate stock-qualified candidates and retain whole-basket provider authority. Reject encoded native arrays before expansion and include available nested field/type paths in binding diagnostics without correcting the submitted plan. Diagnose independent binding failures together with plan paths and explicit field/type requirements; never silently declare fields, coerce validity types, fix model plans or emit source from a rejected plan.

core/composition/formula.deal owns pure formula grammar; the legacy native formula adapter belongs only in consuming fixtures, not the library. Generate closed configuration shape checks from ui/fragment-contract.json rather than maintaining a second shape inventory. Resolve all references before emitting nodes; keep provider invocation, mutation, arbitrary calls and source syntax outside the grammar. Formula strings are not executable DEAL or JavaScript. Do not copy reference length ceilings or numeric comparison/division coercions from OHOS.

Keep checking distinct from native authorization and activation. Preserve existing compiler and Deal UI semantics when changing the embedding path.
