# Bindings

Serialize generation catalogues canonically: stable object keys and module/function order, preserving positional parameter arrays and all contract facts. Catalogue revisions and model prefixes must consume the same bytes, never a different provider schema.

Derive application declarations and sandbox configuration from provider contracts. Convert wire records to DEAL tables and back according to their schemas. External parameter names are wire metadata; emit safe positional parameter identifiers in DEAL declarations. Escape generated DEAL strings using DEAL rules, not JSON escaping.

`ExperienceGenerator` services core discovery, choice, model and checker calls and owns checked staging cleanup. Keep application capability execution in experience sessions. Expose provenance and typed generation rejection from the trusted core result; never infer authorship or failure classification from source text or user-visible exception strings.

`ProtocolController` bootstraps ordinary compiled DEAL consumers with a trusted local synchronous controller and nonblocking native mechanism lanes. Preserve control availability while inference is awaiting, including noncooperative remote computation. Application generation waits for completion or explicit cancellation; do not apply the ordinary mechanism-call wall-clock deadline to a multi-attempt generation. Do not expose controller bookkeeping or native resource handles to generated UI. `ApplicationProtocol` links native rendering/lifecycle inputs to the compiled application consumer. Do not restore direct native application orchestration or a second public dispatch adapter. Internal drivers must service progress without next calls; pending next waits must never occupy the serialized mechanism lane. Detaching observation must cancel its transport wait, native waiter and result bookkeeping without closing execution. Complete the local wait even if the consumer isolate cannot service detach. Retain failed release ownership; synchronous handle retirement must not turn physical cleanup failures into log-only loss. Reclamation failure must never veto shutdown: adapters and subscriptions as well as controllers must attempt every driver, wait, executor, isolate and engine teardown, then report aggregated failures. Preserve typed mechanism and generation-reason codes across the DEAL error boundary. Synchronous permission admission reads trusted isolate epochs, not queued native grant notifications. Preserve compiler-issued nominal identities, including Deal UI tree/prop classes, without leaking metadata into constructors. `ChoiceProtocol` validates generic offer/answer coverage and numeric bounds; app-linked DEAL owns equipment eligibility and source synthesis. The native checker classifies only typed candidate rejection. A rejection with suppressed cleanup failure is operational and stops repair; preserve bounded suppressed code/message evidence through trusted result transport. Shape conversion and UTF-16 are mechanisms, not semantic fallback decisions. Generated UI never receives the public administration inventory.

Generation telemetry observes the authoritative core's patch/check/model boundaries; never duplicate native tool execution, admission or repair decisions in Kotlin. Read edit counts from the core's parsed result, not model JSON. Optional trusted candidate tests execute real isolated sessions, return observed failure feedback to core exact-patch repair, and never expose test authority to generated code. Provider failures are classified and delivered to core recovery; cancellation must remain responsive. Do not hard-stop on arbitrary attempt counts or incomplete model envelopes. Preserve request/attempt/check correlation and immediate versus initial-source baselines. Source changes and resolved diagnostics do not establish behavior preservation: absent explicit evaluation remains not tested. Summaries must preserve unknown usage and independent check/mount/publication milestones, including failure/cancellation.

Use the single compiled `core/logging.deal` contract through `EmbeddingLog`. Keep native adapters limited to admission, clock, hashing, storage and independent isolate execution; never use generated UI isolates to service logger calls. Routine events exclude raw content; capture artifacts only with explicit private opt-in. Capture uses one app-private persisted choice shared by active protocol instances and Inspect; opening or closing another controller must not replace/reset it. Complete capture changes synchronously before returning. Preserve parent/span relationships and report dropped/incomplete data. Never log credentials or authorization headers. No parallel trace/receipt loggers or logged/unlogged transport overloads. Logger admission and optional host diagnostic file writes must preserve application results and original errors. Keep logger flush/span helpers internal; app debugging readers use source/events/artifact/health protocol operations. Health must distinguish active failure from recovered incomplete history rather than silently erase loss.

`DealSessionBindings` loads Deal UI's packaged JS session runtime before the embedding transport adapter. Keep drain/completion/fault/replacement policy in Deal UI, not embedding bindings. Hosts implement module loading and Promise scheduling; preserve generated store, action, effect and reconciliation semantics.

`TrustedProgram` executes only app-linked compiled policy with explicitly supplied mechanisms, isolated from generated UI. It owns asynchronous servicing and shutdown; hosts must not build their own evaluator/pump. Built-in trusted data/choice mechanisms normalize shapes and transport issued questions without domain interpretation.

Share observed activity labels, captured argument decoding and request/reply/check correlation, including on-device opportunity inference, through ObservationPresentation; app Inspect screens select experience/request scope and native presentation, not duplicate trace joins, stage-link traversal or protocol decoding. ObservationPresentation consumes only public events/artifact/trace contracts; use the canonical Event.experience field, not native workspace/candidate aliases. Preserve incomplete pages and never invent evicted links. TrustedProgram exposes its observation trace for scope linkage, never execution authority.

Share evaluation and module bundling through `SandboxProgram` and `SandboxBundle`. Keep generation and experience host-module inventories separate. Confine loading to compiled bundle modules and configured contracts.
