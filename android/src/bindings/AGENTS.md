# Bindings

Derive application declarations and sandbox configuration from provider contracts. Convert wire records to DEAL tables and back according to their schemas. External parameter names are wire metadata; emit safe positional parameter identifiers in DEAL declarations. Escape generated DEAL strings using DEAL rules, not JSON escaping.

`ExperienceGenerator` services core discovery, choice, model and checker calls and owns checked staging cleanup. Keep application capability execution in experience sessions. Expose provenance and typed generation rejection from the trusted core result; never infer authorship or failure classification from source text or user-visible exception strings.

`ProtocolController` bootstraps ordinary compiled DEAL consumers with a trusted local synchronous controller and nonblocking native mechanism lanes. Preserve control availability while inference is awaiting, including noncooperative remote computation. Do not expose controller bookkeeping or native resource handles to generated UI. `ApplicationProtocol` links native rendering/lifecycle inputs to the compiled application consumer. Do not restore direct native application orchestration or a second public dispatch adapter. Internal drivers must service progress without next calls; pending next waits must never occupy the serialized mechanism lane. Detaching observation must cancel its transport wait, native waiter and result bookkeeping without closing execution. Retain failed release ownership; synchronous handle retirement must not turn physical cleanup failures into log-only loss. Reclamation failure must never veto shutdown: adapters and subscriptions as well as controllers must attempt every driver, wait, executor, isolate and engine teardown, then report aggregated failures. Preserve typed mechanism and generation-reason codes across the DEAL error boundary. Synchronous permission admission reads trusted isolate epochs, not queued native grant notifications. Preserve compiler-issued nominal identities, including Deal UI tree/prop classes, without leaking metadata into constructors. `ChoiceProtocol` validates generic offer/answer coverage and numeric bounds; app-linked DEAL owns equipment eligibility and source synthesis. The native checker classifies only typed candidate rejection. A rejection with suppressed cleanup failure is operational and stops repair; preserve bounded suppressed code/message evidence through trusted result transport. Shape conversion and UTF-16 are mechanisms, not semantic fallback decisions. Generated UI never receives the public administration inventory.

Use the single compiled `core/logging.deal` contract through `EmbeddingLog`. Keep native adapters limited to admission, clock, hashing, storage and independent isolate execution; never use generated UI isolates to service logger calls. Routine events exclude raw content; capture artifacts only with explicit private opt-in. Preserve parent/span relationships and report dropped/incomplete data. Never log credentials or authorization headers. No parallel trace/receipt loggers or logged/unlogged transport overloads. Logger admission and optional host diagnostic file writes must preserve application results and original errors. Keep logger flush/span helpers internal; app debugging readers use source/events/artifact/health protocol operations. Health must distinguish active failure from recovered incomplete history rather than silently erase loss.

`DealSessionBindings` loads Deal UI's packaged JS session runtime before the embedding transport adapter. Keep drain/completion/fault/replacement policy in Deal UI, not embedding bindings. Hosts implement module loading and Promise scheduling; preserve generated store, action, effect and reconciliation semantics.

Share evaluation and module bundling through `SandboxProgram` and `SandboxBundle`. Keep generation and experience host-module inventories separate. Confine loading to compiled bundle modules and configured contracts.
