# Rendering

Render checked portable trees in Compose. Preserve structural/key identity and forward compiler-issued action slots and typed payloads.

`RenderComponent` defines implemented components and capabilities. Keep dispatch exhaustive and registration aligned with the pack.

`EmbeddedExperience` marks the generated surface. Place native permission, consent and confirmation controls outside it.

Use pack-defined props and events. Keep application transitions and validation in DEAL. Input controls render supporting/error text and enabled state without inventing validation. Integer steps must avoid overflow, honor limits and expose distinct accessible increase/decrease controls. Search input uses the same string payload boundary as text input. Use native Material typography and minimum 48 dp action targets; hero text must not overwhelm the task controls. Do not strip source text to hide engineering copy; fix authored templates and guidance instead.
