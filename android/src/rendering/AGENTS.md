# Rendering

Preserve fractional numeric keys as numbers. Components whose contracts represent whole units must reject fractional/nonfinite/out-of-native-range props before conversion, never silently truncate the shared `number` lane.

Render checked portable trees in Compose. Preserve structural/key identity and forward compiler-issued action slots and typed payloads.

`RenderComponent` defines implemented components and capabilities. Keep dispatch exhaustive and registration aligned with `ui/platform.dealui-pack`. Adaptive rows must measure checked children without swapping composition branches on resize; account for font scale and preserve keyed identity. Money formats explicit integer minor units/currency; Comparison displays DEAL-supplied status and never infers conclusions. Required props and child composition are checked in Deal UI, not Kotlin. Use native typography, inherited themes and explicit text labels rather than color-only meaning. Comparison may use the inherited primary accent for hierarchy, never select a domain success/error color from values or status prose. Keep subordinate actions visually quieter than primary actions and center numeric values on a stable step-control grid. Comparison values share aligned label/value rows on phones; stack labels and amounts at large text sizes rather than compressing either, and keep all checked children in authored order.

`ExperienceSurface` owns routine run/next/render/event/publication wiring through the compiled application consumer. Failed close must still stop the action executor and fence callbacks; retain unsuccessful cleanup handles for retry. Hosts explicitly activate and close its owner off the UI thread; composition detaches rendering and its cancellable observer, never silently closes execution or deletes source. Reactivation of a retained owner must detect terminal execution and explicitly cold-recover; never trust a cached Session alone. Fence late callbacks by owner epoch. Share copy-only display-prop traversal; app formatting must not rewrite input values or payloads. Acknowledge acceptance after successful Compose composition, not on receipt and not as proof of pixels displayed. Preserve the originating owner in widget callbacks and publication; never consult a global latest session. A received snapshot may precede recomposition: keep callbacks from the last accepted, still-rendered frame admissible for that live owner, while runtime current-tree slot validation remains authoritative. Fence detached/closed/replaced ownership and do not silently drop rapid edits solely because a newer snapshot arrived. Keep optional presentation/domain hooks separate from session driving. Surface callback failures must be retained through public observation under content-capture policy, not only reduced to a generic shell message. Snapshot diagnostic hooks must not propagate storage failures into composition or session progress. `EmbeddedExperience` is only the visual frame. Place native permission, consent and confirmation controls outside generated content.

Use pack-defined props and events. Honor pack defaults for omitted tree props: enabled defaults to true, while checked/selected default to false; IntField minimum/maximum/step default to 0/999/1. Explicit enabled=false must remain disabled. Keep application transitions and validation in DEAL. Input controls render supporting/error text and enabled state without inventing validation. Integer steps must avoid overflow, honor limits and expose distinct accessible increase/decrease controls. Search input uses the same string payload boundary as text input. Use native Material typography and minimum 48 dp action targets; hero text must not overwhelm the task controls. Do not strip source text to hide engineering copy; fix authored templates and guidance instead.
