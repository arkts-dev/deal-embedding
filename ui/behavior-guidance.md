# Maintained fragment composition

The framework assembles `{title,fragments,commands,display}` after typed needs, bounded candidate selection and admission; this is not a model submission tool. Each fragment has unique [A-Za-z][A-Za-z0-9_]* id, kind, closed config. The maintained fragment owns state, handlers, views, validation/lifecycle. Do not author a state/action/node graph. Display lists visible IDs in order. Commands contain id/label/targets; dependency execution is derived. One command owns each provider resource and its explicit refresh; independent commands remain independent. Local-only compositions use commands:[]. Reads require explicit action, never generation/mount. Jev selects issued alternatives; ordinary compiler checking remains authoritative.

Formulas are `{expr:"..."}` using actual ID.port: amount.value, resource.result.field. Bare IDs and literal instance/port placeholders are invalid. alternatives publishes baskets; quotes publishes results. Use reply.field only inside quote reply projections (cost/deposit/available/ttlMillis), item.field for basket arguments, row.field for collection bodies. Never use reply outside those quote config projections. Allow literals, parentheses, + - * /, === !== < <= > >=, && || !, floor/ceil/abs/choose/clock/integer/concat/length/sum/filter/any/all/project. Strings use double quotes; clock(minuteOfDay) formats HH:mm. No assignment, source, arbitrary calls or provider emulation. Collection calls have exactly two arguments: sum(rows, row.cost), filter(rows, row.eligible), any(rows, row.enabled), all(rows, row.enabled), project(rows, row.id). No arrows, lambdas, method calls, ternaries, single-quoted strings or one-argument sum(project(...)); use sum(rows, row.cost) directly. choose(condition, yes, no) is the conditional. Imports are local ports name.value; do not recreate imported inputs or read parent IDs. Contracts determine types/presence; reject missing/incompatible ports/cycles. Editable inputs remain references, not frozen request literals.

- input: label, format integer/money/time/text/boolean, value, minimum/maximum (zero for text/boolean). Money is integral minor units; never multiply already-minor-unit facts. Require minimum <= value <= maximum; time bounds 0..1439. Publishes value.
- read: disclosed {module,function}, formula arguments in parameter order. Publishes result/present, preserving nested/optional schema.
- result: label, format money/time/number/integer/text, value formula. Publishes value/present; hide while dependencies absent.
- comparison: limit/actual formulas, label; separate input fragments provide editing. Publishes only signed difference/present (not value/result/status), displays magnitude and over/under/equal. Downstream feasibility uses difference <= 0 for actual <= limit.
- choice: source array; row identity/label/eligible/cost. Initially selects cheapest eligible option; every option remains selectable with validity. Publishes selected {id,label,eligible,cost}/present; IDs are provider-owned.
- allocation: source; row identity/label/cost/eligible; total/budget/surcharge; quotas [{label,minimum,predicate}]. Quotas may overlap. Whole quantities have no fixed row/quantity ceiling; quantities/budget/choices remain editable. Publishes rows/total/valid/present; present requires current inputs, valid also feasibility. Load source/prerequisite choices in one command closure. Failure cannot retain Ready.
- alternatives: catalogue source; row identity/label/stock; components {source,identity,quantity}, where source is each row's component array, not the catalogue. Roles [{label,quantity,predicate}] require distinct physical units even when predicates overlap. Resolve one-level bundles against catalogue identities and aggregate shared stock. Publishes stock-qualified baskets {items,key,label}. Preserve all material constraints and disclosed vocabulary; never invent attribute paths, connector spellings or fixed role counts.
- quotes: baskets, disclosed binding, ordered arguments: {kind:"value",value:formula} or {kind:"basket",encoding:"idQuantity"|"records",idField,quantityField}. Preserve offset-bearing instants as text/constants, never clock-only or appended Z. Encode real IDs/quantities in declared types. cost/deposit/available/ttlMillis read reply; budget references current input. Whole-basket provider prices/deposits are authoritative. Each reply retains its own conservative receipt expiry, not batch completion; SessionClock invalidates trust on suspend/reopen/backward signals. Explicit refresh. Publishes results, including over-budget offers: rows have exactly key:string, label:string, cost:number, deposit:number, available:boolean, expiresAt:number. Provider reply fields are mapped to those maintained names; outside quote config use row.cost/row.deposit, never reply.cents or row.cents. These results are alternatives, not one combined basket: never sum competing quote costs/deposits. Separate hire/refundable deposit.

Nested configs/arguments/roles/quotas are actual arrays/objects, never JSON strings. Authorized facts determine requirements/initial values, not expected answers. Providers own IDs/eligibility/stock/prices. Missing matches, infeasibility and operational failure differ.

submit_section fills issued typed imports/exports/capabilities with a nonrecursive maintained subtree; core namespaces owned state/actions/view roots and rejects neighbor references/calls. submit_custom fills issued pure interfaces only. Three charged local invocations: initial, diagnostic, thinking. Preserve independent sections/notices; source_fallback requires real checked absence of runnable task subsets. Provisional compiler probes precede one canonical materialization. Then canonical decoded source alone governs read_file/edit_sources/check_sources. Do not reassemble or overwrite. Charge every rejection/fallback/custom character/exact repair; rejected composition leaves the workspace unchanged.
