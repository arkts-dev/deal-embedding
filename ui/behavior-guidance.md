# Maintained behavioral composition

Use submit_compact first. Supply a typed operation graph, not DEAL expressions, functions, bodies or view source. The tool schema is the executable vocabulary. State initial and literal value are JSON-encoded data (for a string, include JSON quotes); neither accepts executable expressions. References use $state.field, $action.field, $row.field or $workflowStep.field. Other strings in argument/binding positions name expression nodes. All records/fields are explicitly typed; no implicit provider records. Project provider records into local declared types before storing them. Arrays use Type[].

Nodes own actual computation: arithmetic, comparison, boolean, choose, integer/clock formatting; record/array construction; filter/project/sum/any/all, stable sort, lookup, fresh immutable update, basket serialization, allocation and component coverage. Dependencies are derived from references. No independent depends list. record/update params.fields is a list of {field,node} bindings. Row transforms bind $row. Nested transforms bind their own row. join takes [leftRows,rightRows,predicate,projection] and binds $left/$right in predicate/projection, emitting stable matching projections. Use it for typed ID joins without inventing positional relationships. first/lookup return a typed empty value when absent; validate presence/IDs before showing success or calling providers.

allocate takes [rows,total,budget], params quantity/cost naming numeric fields, and quotas [{field,minimum}] over boolean category fields. It searches nonnegative whole quantities for exact total and category minima within cost ceiling, using stable input order. No found solution means zero quantities; distinguish this from success through count/category/cost validity. Subtract actual selected delivery cost before allocation. Editable rows remain available when infeasible. Do not report infeasibility merely because a search failed operationally.

covers takes [packageRows,catalogue] and resolves component IDs/quantities using explicit components/key/itemId/quantity field names. groups [{predicate,minimum}] count matching component quantities. Predicates inspect actual structured attributes, not display names. basket serializes positive integral quantities as ID:quantity pairs. Provider quote remains authoritative for the whole basket, shared stock, deposit and expiry; never add independent quotes/deposits to invent a basket quote.

Actions contain typed fields, local updates and an ordered steps list. call steps name disclosed module/function, exact argument nodes, unique result ID and optional state bind/node projection and when guard (empty means unconditional); a false guard skips the call; $stepIdPresent explicitly reports whether the provider call ran, while its typed empty result alone is not evidence of success. Clear prior result state explicitly before conditional workflows so missing alternatives cannot retain an old quote. set steps bind a computed node. References to earlier result IDs derive workflow order; forward/unknown references are rejected. Provider arguments and result decoding are checked against complete disclosed contracts. Optional provider fields expose present/value; choose a documented absence policy explicitly. Reads occur only on user action, not initialization. One action may perform menu then delivery then allocation, or equipment then whole-basket quote alternatives. Failure is not a successful empty/zero-price result. Add a useful retry action and progress/error views. Do not hide missing behavior with an empty screen.

State fields used for derived conclusions must be recomputed after edits. Numeric controls specify widget integer/money/time, explicit integral bounds/step and boolean invalidate fields. invalidate is a list of BOOLEAN state field names to set false, never numeric cached values: keep a separate boolean validity flag for provider results. money stores integral minor units. time stores minute-of-day and renders HH:mm. Distance/period changes invalidate provider-derived results; local budgets recompute without reads. Immutable row updates rebuild arrays using captured opaque IDs, never labels or indexes. Validate numeric event payload bounds/integrality through nodes before updates.

Views are pack component nodes, with typed props {name,node}, children IDs, optional each reference/key, optional when scalar reference, and events {name,action,payload:[{field,node}]}. Bind props to scalar state/row references or literal nodes. Compute nontrivial presentation in derived state, not UI calls. Event payload uses $payload. Match the pack's required props/typed children/events. SessionClock emits epoch milliseconds, negative epoch milliseconds on mount/resume: clear age trust then, while storing its absolute time. DEAL owns expiry and must not refresh quotes automatically. Record quote expiry from receipt-time ticks (not action-start snapshots); preserve invalidation across restoration, and require explicit refresh when age is untrusted.

Custom DEAL is supported only as an explicit slow path. submit_custom adds a reason and named custom functions with typed parameters/result/body; invoke through custom nodes. Bodies obey ordinary compiler and borrowed-state checks. Missing maintained coverage for known requirements is not a reason to omit them. Full-source source_fallback is the last resort. Once any pair is materialized, canonical DEAL/Deal UI is sole authority: use read_file/edit_sources/check_sources only, never submit/reassemble/overwrite. All preceding work, fallback reasons/custom volume and source repairs remain measured.
