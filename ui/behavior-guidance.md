# Maintained behavioral composition

Use the matching submit_compact_comparison, submit_compact_providerSchedule, submit_compact_allocation or submit_compact_quotedAlternatives tool. Select one maintained behavior and supply its requirements plus exact disclosed provider and field bindings. The maintained fragment owns state, handlers, sequencing, recomputation, validation, failure/retry, input invalidation, keyed edits and views. Do not author a state/action/node graph for supported behavior.

- comparison: editable limit and actual in integral minor units, labels, signed difference and over/under/equal.
- providerSchedule: editable start (minute of day), numeric provider input, before-start and inspection buffers in minutes; estimate binds a disclosed number-to-number provider. The provider supplies travel duration; never reproduce its formula. Input changes revoke result validity; local time/buffer changes recompute.
- allocation: editable total, minimum category count, budget in minor units and deadline in minutes of day; size in disclosed numeric units. menu binds a no-argument array read; delivery binds a string HH:mm deadline read. fields explicitly bind catalogue identity/name/cost/boolean category/numeric size and window identity/start/end/eligibility/delivery cost. One action loads both, chooses an eligible low-cost delivery and allocates whole quantities. Quantities, budget and window remain editable with current validity; failure never preserves a Ready conclusion.
- quotedAlternatives: explicit period instants and editable hire budget. catalogue binds a period-to-array read; quote binds items/from/until to an authoritative whole-basket reply. fields bind item identity/name/cost/stock/components, component identity/quantity and quote cost/deposit/availability/TTL in minutes. groups is JSON-encoded data containing two requirement groups [{label,constraints:[{field,operator,valueType,text,number,boolean}]}] with explicit structured attribute constraints (field paths relative to attributes, operators eq/ge/le; valueType string/number/boolean selects text/number/boolean, other value slots stay empty/zero/false). Maintained behavior enumerates stock-qualified matching package and separate baskets, quotes each as a whole, compares authoritative hire, displays deposits separately and expires replies from their own receipt times. No booking. Display prose is not matching evidence. IDs and quantities come from provider records, never task constants.

Each tool takes one behavior directly with title and kind; do not wrap it in a behaviors array. groups is explicitly a JSON-encoded data string; its constraints are arrays inside that encoded data. No source or expressions are accepted. Binding names must match disclosed capability declarations. Constraints and initial values come from the authorized task, never expected test answers. No selector/verifier call. Reads run on explicit user action, never during generation or mounting. SessionClock supplies lifecycle/time signals; DEAL owns trust and expiry. Refresh is explicit.

For genuinely uncovered behavior, submit_custom remains an explicit measured slow path with typed graph/custom function boundaries; full-source source_fallback is the last resort. Neither substitutes for the maintained behaviors above. Once materialized, canonical DEAL/Deal UI is the sole authority: read_file/edit_sources/check_sources only. Do not reassemble or overwrite. Every rejection, fallback, custom character and exact repair remains charged. A rejected composition leaves the workspace unchanged.
