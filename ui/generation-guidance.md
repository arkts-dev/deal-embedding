# Explicit custom/full-source authoring

This guidance applies only to explicit custom sections, full-source fallback and exact-source repair. The maintained first path uses behavior-guidance.md and the typed tool contract, not raw source bodies.

Keep imports first. Export main(): null, State, initialState(): State and all view-visible action/row classes in full source. Every local needs an initializer and every required constructed field a value. Custom sections are function bodies with declared typed parameters/result; do not emit imports, classes or framework handlers there. Do not duplicate framework-owned state copies, recompute, updates or root views.

Use // @ui-update immediately before an exported (state: State, action: Action): State handler. Never mutate borrowed state/action or nested collections. A fresh outer copy does not own nested arrays/records: rebuild only changed arrays/rows and preserve untouched references. Put // @ui-effect before exported async (state: State, action: Request): Completion; request updates mark loading, completion updates clear it. Catch provider failures into honest error completions with explicit retry. No reads from main/initialState; no unsupported effect policies/failure mappers.

Full-source .dealui imports app from ./experience and ui from ./platform.dealui-pack, then // @ui-root and an exported view Workspace(state: app.State): View. Use When(condition) { ... } Else { ... }, ForEach(state.rows, row: app.Row, key: row.id) { ... }, and action app.Action {value: payload}. Views bind checked fields/literals, not calls, assignments, indexing or arbitrary expressions. Prepare computations in DEAL. Required props and typed children remain pack-checked. Money uses integral minor units. TimeField uses minute-of-day. SessionClock emits epoch milliseconds or negative mount/resume invalidation, never a domain conclusion.

Provider results remain authoritative. Read actual returned records after explicit loading; never emulate provider formulas or invent IDs/prices/stock. Contextually type dynamic table reads, including keyword keys via record["from"]. Preserve offset-bearing instants; never append Z to unchanged local time. Quotes cover whole baskets and expire; show hire/deposit separately. Late delivery, invalid quantities, missing matches, pending and failures must not appear as success.

After materialization read_file/edit_sources/check_sources are the only operations. read_file has inclusive bounds; both null for full source. Exact edits must uniquely match current canonical decoded bytes and be disjoint; the host binds revisions. Never resubmit a plan, overwrite, reformat all source or silently regenerate. Tool strings decode to literal source, including actual Unicode, not unsupported backslash-u source escapes. Full language rules come from the current compiler authority; no compatibility lane.
